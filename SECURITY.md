# Security

This offline tool accepts local files and writes only new output directories. It has no server, remote upload, shell execution, network client, or hardware-control endpoint. Inputs have file-type, byte, sample, numeric, duration, metadata, and settings bounds; symbolic links are rejected. These checks do not make arbitrary files or the native scientific runtime a hostile-file sandbox.

Do not place sensitive specimen or instrument information in public reports. HTML reports include user-declared capture identifiers and figures; check their content before sharing. Use GitHub private vulnerability reporting if available. Otherwise open a minimal issue asking for a private contact, without sensitive files or exploit details.
